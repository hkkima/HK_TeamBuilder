# E2E 테스트 (10 · 25 · 60명)

세 가지 규모에 대해 **실제 데이터 생성 → 팀 추천 → 결과 검증**을 종단 간으로 확인합니다.
두 계층(파이썬 CLI / 브라우저 웹앱)이 동일한 보장을 만족하는지 점검합니다.

## 실행

```bash
bash tests/e2e/run.sh          # 둘 다 실행
python3 tests/e2e/run_cli.py   # 파이썬 CLI만
node tests/e2e/e2e.mjs         # 브라우저만 (playwright-core 필요)
```

> 브라우저 테스트는 `tests/e2e/`에서 `npm install`(playwright-core)이 필요하며,
> 사전 설치된 Chromium(`/opt/pw-browsers`)을 사용합니다.

## 검증 항목

데이터는 `data/make_sample.py`로 규모별 생성합니다. 갈등쌍은 **매칭**(각 사람이
최대 1개 갈등쌍)으로 주입되어 팀이 2개 이상이면 항상 갈등 0 분리가 가능합니다.

공통 보장 사항:
- 인식 인원수가 입력 N과 일치
- 추천안 1~3개 생성, 서로 다른 구성
- 최상위 추천안: 전원이 정확히 1회 배정(누락·중복 없음)
- 팀 개수 일치 / 팀 크기 합 = N / 팀 크기 균형(차이 ≤ 1)
- **최상위 추천안의 같은 팀 내 갈등쌍 0개**
- (CLI) 주입한 갈등쌍을 관계 그래프가 전부 탐지

브라우저 전용 추가 검증:
- 로그인 게이트: 잘못된 PW 차단 + 오류 메시지 / 올바른 자격증명 통과
- CSV 내보내기 다운로드: 행 수 = 1(헤더) + 추천안 수 × N, 헤더 형식

### 운영진 강제 규칙 검증 (브라우저, N=25)
- 강제 결합 쌍이 같은 팀에, 강제 분리 쌍이 다른 팀에 배치되는지(CSV로 확인)
- "운영진 강제 규칙 모두 충족" ✅ 플래그 표시
- 모순 제약(같은 쌍 결합+분리) → 오류 메시지
